# ШУКО

Редизайн сайта schuecohome.ru: вёрстка по макету из Figma.

## Текущий сайт (что заменяем)

- CMS: 1С-Битрикс (картинки лежат в `/upload/iblock/` и `/upload/medialibrary/`)
- Один собранный `css/style.css`, слайдеры Swiper и Slick, SVG-спрайт иконок
- Шрифт Stem (ParaType), веб-версии Medium и Regular
- Счётчик Яндекс Метрики

## Вёрстка

Чистые HTML, CSS и JS без сборки, чтобы потом легко перенести в шаблон Битрикса.

- `index.html`: адаптивная главная по desktop/tablet/mobile-кадрам макета
- `project.html`: страница проекта Villa Kymmendö целиком — первый экран, «О проекте», галерея, «Системы Schüco», контакты и форма
- `world.html`: «Мир Schüco» — первый экран с цифрами, разделы «О компании» и «Подход», две карточки, история по годам, карта партнёров
- `partners.html`: «Партнёры» — первый экран, «Экосистема Schüco», вкладки и сетка карточек, контакты и форма
- `partner.html`: «О партнёре» (шаблон, партнёр-заглушка kestrel из макета) — первый экран, текст, проекты, галерея, контакты с картой, форма
- `solutions.html`: «Решения» — первый экран, 12 сценариев (карточки ведут на «Решение»), чёрный блок с двумя кнопками
- `solution.html`: «Решение» (шаблон, «Панорамное остекление» из макета) — первый экран, «Решение Schüco», конструкции, на что обратить внимание, подходящие системы, проекты, чёрный блок с кнопками
- `systems.html`: «Системы_окна» — первый экран, «Окна Schüco» со списком и «Смотреть все», таблица ключевых параметров, галерея объектов, системы AWS 75.SI+ / AWS 90.SI+
- `blog.html`: «Блог» — заголовок, 6 карточек статей (ведут на article.html), пагинация, чёрная форма подписки
- `css/style.css`: стили, брейкпоинты по макету: 1920 (десктоп), до 1199 (планшет 834), до 599 (мобильный 400)
- `js/main.js`: навигация, интерактивные проекты и партнёры, карта, меню и попапы форм
- `js/world.js`: разделы-аккордеоны, ряд разделов в шапке, кнопка «Смотреть все» в истории
- `js/project.js`: ряд разделов в шапке при прокрутке, листание галереи, демо-отправка формы проекта
- `assets/`: шрифты Stem с текущего сайта, логотип, фото и данные партнёров

Главная включает первый экран, манифест, решения, реализованные проекты,
юбилейный блок, «Наши люди», журнал, карту партнёров и футер. Состояния
«Обсудить проект» и «Подписка на рассылку» собраны по отдельным кадрам макета.
Отправка форм остаётся демонстрационной до переноса в шаблон и подключения
обработчиков 1С-Битрикс.

Страница проекта повторяет кадры 1920 / 834 / 400: название с локацией, фото, строки
«О проекте», галерея с листанием, шесть строк систем и чёрная форма с контактами.
В макете все шесть строк систем — заглушка «AWS 75.SI+»; названия оставлены как в макете.

Страница «Мир Schüco» собрана по кадрам 1920 / 834 / 400. Текст в истории в макете есть только
у 1951 года, у остальных событий — название и год. Скрытый в макете блок «Наши бренды» не верстался.
Карта партнёров — тот же живой блок, что на главной, на десктопе список слева, карта справа.

На странице «Партнёры» карточки — первые 9 партнёров из assets/data/partners.json (в макете везде заглушка
ALSECO), вкладки переключаются без фильтра, как на главной; контакты и форма — блок со страницы проекта.

«О партнёре» собрана из готовых блоков: первый экран «Мира Schüco», «Реализованные проекты» главной, галерея
и форма страницы проекта. Тексты, цифры и контакты — из макета (там заглушки). Карта — живая, с одной меткой;
координаты шоурума примерные. Скрытый в макете список систем не верстался.

«Решения»: названия, описания и фото 12 сценариев — из макета; у «Максимально тонких рам» в макете
повторён текст «Выхода на террасу», опечатка «раздвиюжные» исправлена.

«Решение» собрана из готовых блоков: первый экран «Решений», вводный текст, «Реализованные проекты» главной
(строки — заглушки из макета) и чёрный блок с кнопками. Новый только блок подробностей: на десктопе одна строка «01»,
на планшете две — «01» и «02». В мобильном кадре макета в первом экране осталась заглушка «Villa Kymmendö» —
взят заголовок решения, поэтому экран на две строки выше кадра.

«Системы_окна»: первый экран «Мира Schüco», галерея «О партнёре» (первое фото узкое), строки систем со страницы
проекта с фото справа (фото — из сценария «Угловое остекление», как в макете). В списке «Что можно реализовать»
4 пункта видны, ещё 6 скрыты в макете — их раскрывает «Смотреть все». Блока «Системы Schüco» нет в планшетном
и мобильном кадрах — адаптация своя. В мобильном кадре текст в таблице параметров не помещается в строки —
строки растут по тексту. Подписи в галерее — заглушки из макета.

«Блог»: карточки статей при наведении размывают фото и показывают «Смотреть» (вариант 2 компонента «Статья»;
в макете в этом варианте название переезжает над фото — оставлено под фото). Пагинация есть только в десктопном
кадре — оставлена на всех ширинах, активная страница 1. Форма подписки — чёрная форма «О партнёре» с полями
из попапа подписки; в планшетном кадре в ней лишние поля из формы заявки, они не верстались.

Локальный просмотр: `python -m http.server 4490`
