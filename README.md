# ШУКО

Редизайн сайта schuecohome.ru: вёрстка по макету из Figma.

## Текущий сайт (что заменяем)

- CMS: 1С-Битрикс (картинки лежат в `/upload/iblock/` и `/upload/medialibrary/`)
- Один собранный `css/style.css`, слайдеры Swiper и Slick, SVG-спрайт иконок
- Шрифт Stem (ParaType), веб-версии Medium и Regular
- Счётчик Яндекс Метрики

## Вёрстка

Чистые HTML, CSS и JS без сборки, чтобы потом легко перенести в шаблон Битрикса.

- `index.html`: адаптивная главная по desktop/tablet/mobile-кадрам макета
- `project.html`: страница проекта Villa Kymmendö целиком — первый экран, «О проекте», галерея, «Системы Schüco», контакты и форма
- `world.html`: «Мир Schüco» — первый экран с цифрами, разделы «О компании» и «Подход», две карточки, история по годам, карта партнёров
- `css/style.css`: стили, брейкпоинты по макету: 1920 (десктоп), до 1199 (планшет 834), до 599 (мобильный 400)
- `js/main.js`: навигация, интерактивные проекты и партнёры, карта, меню и попапы форм
- `js/world.js`: разделы-аккордеоны, ряд разделов в шапке, кнопка «Смотреть все» в истории
- `js/project.js`: ряд разделов в шапке при прокрутке, листание галереи, демо-отправка формы проекта
- `assets/`: шрифты Stem с текущего сайта, логотип, фото и данные партнёров

Главная включает первый экран, манифест, решения, реализованные проекты,
юбилейный блок, «Наши люди», журнал, карту партнёров и футер. Состояния
«Обсудить проект» и «Подписка на рассылку» собраны по отдельным кадрам макета.
Отправка форм остаётся демонстрационной до переноса в шаблон и подключения
обработчиков 1С-Битрикс.

Страница проекта повторяет кадры 1920 / 834 / 400: название с локацией, фото, строки
«О проекте», галерея с листанием, шесть строк систем и чёрная форма с контактами.
В макете все шесть строк систем — заглушка «AWS 75.SI+»; названия оставлены как в макете.

Страница «Мир Schüco» собрана по кадрам 1920 / 834 / 400. Текст в истории в макете есть только
у 1951 года, у остальных событий — название и год. Скрытый в макете блок «Наши бренды» не верстался.
Карта партнёров — тот же живой блок, что на главной, на десктопе список слева, карта справа.

Локальный просмотр: `python -m http.server 4490`
